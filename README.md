# アストロ・スタディ

宇宙飛行士選抜試験（一般教養・基礎的専門）対策の学習アプリ（PWA）。

## 中身
- 15科目 × 各25問 ＝ 375問（基礎120・標準135・発展120、図つき30問）
  - 人文科学：日本史・世界史・地理・思想・文学芸術
  - 社会科学：政治・法律・経済・社会時事
  - 基礎的専門：数学・化学・物理・生物・地学・宇宙開発
- 本日のミッション（1日のノルマ・復習の割合・科目配分・レベルを設定）
- 間違えた問題の復習（翌日→3日後→7日後→14日後、4回連続正解で卒業）
- 模擬試験（総合／一般教養／基礎的専門、時間制限つき）
- 成績（直近14日・科目別・レベル別・苦手科目）
- 要点ノート（15科目・計102項目。表・図つき。問題の解説画面からも開ける）
- 学習記録のバックアップ／復元

問題は国家公務員試験などの出題形式を参考にしたオリジナル問題です。

## ファイル構成
```
index.html / styles.css / app.js   アプリ本体
data/subjects.js                   分野・科目・レベル定義
data/notes-*.js                    要点ノート（人文・社会・STEM）
data/q-*.js, data/q2-*.js          問題データ
icons/                             アイコン（宇宙飛行士）
manifest.webmanifest / sw.js       ホーム画面追加・オフライン用
```

## 問題の追加方法
`data/q-*.js` または `data/q2-*.js` の `QB.add([...])` に次の形式で追加する。
```js
{id:'phys-2-6', s:'phys', l:2, q:'問題文', c:['選択肢1','2','3','4','5'], a:0, e:'解説', fig:'<svg>…</svg>'}
```
- `s` 科目ID、`l` レベル（1〜3）、`a` 正解の番号（0始まり）。選択肢は表示時にシャッフルされる（`ns:true` で固定）。
- `fig`（問題の図）と `efig`（解説の図）は任意。
- ファイルを更新したら `sw.js` の `VERSION` を上げる。

## Macで確認
```bash
python3 -m http.server 8765 --directory ~/AI用/astro-study
```
ブラウザで http://localhost:8765 を開く。

## GitHub Pages で公開して iPhone に入れる
1. GitHub でリポジトリ（例：`astro-study`）を作成し、このフォルダの中身を push する。
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存。
3. 数分後に表示される `https://<ユーザー名>.github.io/astro-study/` を iPhone の Safari で開く。
4. 共有ボタン →「ホーム画面に追加」。宇宙飛行士アイコンで起動できる。

学習記録は端末のブラウザ内に保存される。機種変更の前には「設定 → バックアップを書き出す」を使う。
